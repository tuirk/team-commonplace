# Quick start

Larchmont Studio is a made-up web studio of seven people: two founders, a project manager, two designers, a developer and an operations lead. Everything in these folders is invented, so you can try things out freely.

## What each folder holds

- The sample-team folder is the studio's commonplace book. Its last project, Halden Bakery orders, finished at the start of November, and the entries from its four Monday week closes name the project in their source.
- The raw folder holds material to try adding entries with: a client call note, a team chat and an article.
- The raw/week folder holds one week on the studio's open project, the Ombrell Pottery site, from 2 to 6 November: the cards closed that week, a call note and the team chat, ready for closing the week.
- prompts.md holds seven prompts to try, with what should happen for each.
