# Changelog

## 1.0.0 (2026-11-15)

First release: six Claude skills as one plugin and as single skills (setup, add, find, close the week, start a project, close a project), the Commonplace Starter web app, and a quick start with a sample team of seven.

## Checked against current docs

Each install and plan claim in README and INSTALL was checked against these pages on the date shown.

- Installing from the GitHub repo (`claude plugin marketplace add tuirk/team-commonplace` or `/plugin marketplace add` with an `owner/repo` source, the marketplace file at `.claude-plugin/marketplace.json` in the repo root and the plugin in `./plugin`; Customize > Plugins > Add > Add marketplace with `owner/repo` on claude.ai and in Cowork, on paid plans, where a Team or Enterprise Owner decides whether members can add marketplaces; `npx skills add owner/repo`, which reads the root marketplace file, finds `plugin/skills/` and needs Node.js 22.20 or later): https://code.claude.com/docs/en/plugin-marketplaces, https://code.claude.com/docs/en/plugins/marketplace-reference.md, https://claude.com/docs/plugins/overview, https://claude.com/docs/cowork/guide/plugins, https://support.claude.com/en/articles/13837440-use-plugins-in-claude, https://github.com/vercel-labs/skills and https://github.com/vercel-labs/skills/blob/main/docs/creating-skills.md, 2026-11-15.
- Claude Code plugin commands (`/plugin marketplace add`, `/plugin install`, and `claude plugin marketplace add`, `install`, `uninstall` and `marketplace remove` in a terminal, with a local folder as the source): the create-marketplace page (https://code.claude.com/docs/en/plugins/create-marketplace), 2026-11-12, and the plugins reference (https://code.claude.com/docs/en/plugins/cli-reference), 2026-11-13.
- Uploading a plugin on claude.ai and in Cowork (Customize > Plugins > Add > Upload plugin; a zip with `.claude-plugin/plugin.json` at its root, or one folder holding it; a paid plan): https://claude.com/docs/plugins/build, https://claude.com/docs/plugins/overview and https://support.claude.com/en/articles/13837440-use-plugins-in-claude, 2026-11-13.
- Uploading a single skill (Customize > Skills > Add > Upload skill, as the menus showed on claude.ai on 2026-11-15, where Customize opens on Discover and uploads are under Yours; a zip holding one skill folder named like the skill; the frontmatter keys name, description, license, compatibility, metadata and allowed-tools): https://support.claude.com/en/articles/12512180-use-skills-in-claude, https://claude.com/docs/skills/how-to and https://code.claude.com/docs/en/skills, 2026-11-13.
- Plans and settings (plugins on paid plans; skills on every plan including Free by the help pages, while https://claude.com/docs/skills/overview says paid plans, so README says what to do if Upload skill isn't there; Code execution and file creation, or Create and edit files, under Settings > Capabilities, on by default for individual plans and controlled by an Owner on Team and Enterprise; Cowork on paid plans, using the account's skills and plugins): https://support.claude.com/en/articles/12512180-use-skills-in-claude, https://support.claude.com/en/articles/12111783-create-and-edit-files-with-claude and https://support.claude.com/en/articles/13345190-get-started-with-cowork, 2026-11-13.
- Uploads on claude.ai also load in Claude Code signed in with the same account: https://code.claude.com/docs/en/plugins/loading, 2026-11-13.
- What a plugin can hold on each surface, and its limits (skills are supported everywhere; files stay small and text): https://claude.com/docs/plugins/platform-support, 2026-11-13.
- Scheduled tasks (paid plans; an admin setting on Team and Enterprise; local runs need the computer on and awake with the app open; cloud runs can't write a local folder; a task belongs to the person who made it): https://support.claude.com/en/articles/13854387, https://code.claude.com/docs/en/desktop-scheduled-tasks and https://code.claude.com/docs/en/routines, 2026-11-12.
- Plugin directory checks (a licence, a README, working example prompts, skills only): https://claude.com/docs/plugins/pre-submission-checklist, 2026-11-13.
- Claude Code skill folders (`~/.claude/skills/` for every project, `.claude/skills/` in one project, a new session for a new folder) and the `license` field: https://code.claude.com/docs/en/skills, 2026-11-13.
